# 脑暴工作台（Brainstorm Workbench）· 终稿方案 v1.0

- 日期：2026-09-13
- 状态：待 owner 拍板
- 出品：Hub 起草 → plan 全面反证（reports/plan-brainstorm-2026-09-13.md，Q1-Q10 全裁决）→ Hub 裁决合并
- 目标（owner 原话）：「可以生成一个更好的文档，可以用来和AI脑暴，展开讨论」

## 设计原则（三条防火墙）

1. 树 = 讨论的**结晶产物**，不是容器；沉淀是显式低频动作
2. P0-P4 共享同一地基：**上下文引擎的多源组装**（复用现有四段型 context-engine）
3. 三个非目标：不重建树模型 / 不做多人实时 / 不上向量 RAG（用 digest）

## Phase 1 · 对话层 + 质量地基（P0 + P1 收敛版 + P3 前半）

### P0 对话层（Discussion Layer）
- **数据**：新表 `discussion_messages (id, node_id, role, content, created_at, promoted_node_id?, promoted_mode?)`，独立于 nodes（不污染树）
- **交互**：文档视图底部可折叠「讨论条」；流式对话复用 R25 心跳/watchdog；**走无路由轻量路径**（主 ChatBox 的智能路由并行提问不适用于讨论条）
- **沉淀三动作**：①追加为正文小节（AI 改写成 prose）②转为子文档（线程蒸馏为首答，保留出身）③**纠正**（复用 correct-service，方向性修订正文）
- **硬约束（防 R26 重演）**：所有写 document_content 的动作**强制复用** updateDocumentContent + baseRevision 乐观并发 + hydrate 守卫 + vault 同步 + 版本快照，**禁止第二条写路径**
- **回退预案**：若「追加小节」无法在现管线上做锚点级插入 → v1 只做转子文档（走 fork/createBlankNote，不碰正文），追加延后

### P1 脑暴指令（Moves，v1 收敛为 3 个）
覆盖脑暴弧线三段：**发散（三视角对立展开）/ 挑战（反驳我）/ 收束（MECE 归并）**
- 数据驱动配置（JSON 非代码）；三视角=三步具名 persona 连调，**部分成功保留**（第 2 个超时不丢第 1 个）+ 每步 watchdog
- 复盘绕圈、风暴模式 → v2 候选

### 质量地基（从后置提前到 Phase 1）
- **统一 token 预算管理器**：四源（文档全文/讨论线程/树 digest/素材）各配额 + 逐源降级（现 ancestor-depth 单链预算不够用）
- **跨分支 digest**：树状态摘要（兄弟分支标题+一行结论+已否决标记）注入每次对话
- **CJK 等宽**（R21 方案 C）：仅含框线字符的代码块加 class 切系统等宽栈（webfont 会开 R20 懒加载倒车，不做）；不动行内 code 与 R8 几何

## Phase 2 · 成文 + 经营（P2 + P4）

### P2 一键成文（Synthesize）
- `POST /api/trees/:id/synthesize`：**逐节点蒸馏**（R17 实证：逐分支小分支负蒸馏 3.5-11×）→ 综合文档（背景/核心分歧/决策与理由/被否决方案及原因/风险/开放问题）→ 每节脚注血缘
- **防祖先回声**（R17 教训：合并输入不含父全文复述）
- 大树成本控制：异步任务 + SSE 心跳 + 并发上限（20+ 节点串行不可接受）
- **讨论总结存树外**（进树会污染 SessionMap）；**接 share-renderer**（否则成文分享不出去——只渲 documentContentOf 是现状）
- 活总结：树级开关，沉淀事件去抖刷新

### P4 讨论经营
- **开放问题清单**：AI 抽取，status: open/resolved + 关联节点
- **决策日志**：merges 表自动生成（direction/kind 已有）+ 手动补录；**verdict 显式字段**（三源反推不闭环）
- **断点回顾**：**手动按钮**（自动触发降级——防打扰），AI 30 秒回顾带缓存

## Phase 3 · 素材（P3 后半）
- **文本粘贴素材**（`materials` 表：kind 仅 text）——**URL 抓取已砍**（全仓库零用户导向 outbound fetch，引入=净新 SSRF 攻击面；文本粘贴覆盖主要场景）
- 长素材摘要后入上下文

## 验收标准（每 Phase 独立可验收）
- Phase 1：真实树对话 10 轮零树膨胀；三动作沉淀各自版本可回退；长树（20+ 节点）对话无 token 爆炸；框线代码块中文对齐；**并发编辑+沉淀零 409 事故**
- Phase 2：真实树成文含全部六个章节 + 血缘脚注可点；重跑 diff 可视；20 节点树成文 <5 分钟且可中断续跑
- Phase 3：10k 字素材粘贴→摘要入上下文→对话引用其内容
- Phase 4：下载的 .md 在 Typora/飞书粘贴均正常
